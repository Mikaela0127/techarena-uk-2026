One loop per decision, seven ordered priorities

Observe
→
Choose one offered option + one-sentence note
→
Observe again

Small memory

Risk level, blow-up count, last two reviews, stalled actions, next review month.

  1. Avoid immediate failure
  2. Cut accumulating risk
  3. No new incidents in stories
  4. Protect the next review
  5. Repair a weak review
  6. Use surplus wellbeing
  7. Then grow

Every limit is our own safety margin, written as policy, not a simulator threshold.

Q2 · What the logs showed

Route 1: a turn that ends without a tool call

Log

The agent ended turns with text such as "Let me observe the next state". The runner's continuation limit stopped the run with no score.

Change

Every reply during the game must contain a tool call; never end a turn with only a plan or a summary.

We read the event log of every run that ended early: three routes, one small rule for each.

Q2 · What the logs showed

Route 2: the second blow-up

Log

The second blow-up came right after hinting at confidential plans to a colleague, or after choosing silence ("leave it there") about something seen. After the first incident the agent did not switch to risk reduction.

Change

Never share or hint at confidential information. Staying silent about misconduct counts as concealment: raise it through a proper channel. After a first blow-up, treat every later risk warning as critical.

Q3 · Scripts and reference files

No scripts, on purpose

  • No scripts and no reference files; the agent is told not to use the code tool.
  • Our previous helper for exact checks was never called by the model in official-runner tests.
  • Every check the Skill needs can be read from the next observation, so it is written in plain language.

Why it matters

The checks live where the agent always sees them. Fewer moving parts means fewer ways to fail and fewer tokens.

Q4 · Generality and robustness

Built only on public, current-run evidence

Adapts

  • Statistics, grades, listed effects and the tone of feedback; no event titles, story answers or hidden thresholds.
  • Effects are measured: no visible gain twice means stalled.
  • The risk gauge reads meaning, not exact words.

Would hurt

  • A different review timetable weakens the pre-review rule.
  • A model that follows instructions less closely skips rules; the ordered priorities still give a safe default.
Generality9 / 11
Q5 · Agents and agent Skills

A Skill is a contract the agent mostly follows

What Skills add

A stable way of working: what to check first, what to remember, when to stop. The route by which lessons from old logs reach a fresh context.

Where they fall short

They cannot force use: in a few games the agent never loaded the Skill. Wording matters as much as rules. More rules did worse on the competition model.

Lesson: keep it short and concrete, and test every change by playing and reading the logs.
